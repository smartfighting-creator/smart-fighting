# Smart Fighting — PWA

PWA pubblica dell'Enciclopedia Tecnica Smart Fighting.

## File
- `index.html` — home installabile
- `manifest.webmanifest` — configurazione PWA
- `service-worker.js` — cache/offline
- `icon.svg` — icona PWA
- `offline.html` — fallback offline
- `enciclopedia.html` — enciclopedia interattiva
- `enciclopedia.pdf` — manuale PDF

## GitHub Pages
URL previsto: `https://smartfighting-creator.github.io/smart-fighting/`

In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Installazione
Android/Chrome: aprire il sito HTTPS e scegliere **Installa app**.

iPhone/iPad: Safari → **Condividi → Aggiungi alla schermata Home**.
